Class Calculadora

Classe responsável por realizar operações matemáticas básicas para o aplicativo FinançApp. Permite realizar adição, subtração, multiplicação e divisão.

Author: Victor Hugo de Almeida Barbosa
Version: 1.0


Method Summary

calc

public double calc(int a, int b, java.lang.String op)

Executa uma operação matemática simples entre dois números inteiros com base no operador informado.

  • Parameters: a - primeiro operando, b - segundo operando, op - operador matemático (+, -, *, /)
  • Returns: resultado numérico da operação
  • Throws: IllegalArgumentException - se o operador for inválido ou nulo.

dividir

public double dividir(int a, int b)

Realiza a divisão entre dois números inteiros.

  • Parameters: a - numerador, b - denominador
  • Returns: resultado da divisão como valor real (double)
  • Throws: IllegalArgumentException - se o divisor for zero.
