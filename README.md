## 2. Visão Geral
O projeto consiste no desenvolvimento de um módulo de cálculos matemáticos básicos em Java para a startup fictícia **FinançApp**. O módulo foi desenvolvido com o objetivo de ser utilizado futuramente em funcionalidades de controle financeiro, como orçamento mensal, divisão de despesas, projeção financeira e cálculos auxiliares.

Além do funcionamento correto das operações, o projeto aplica práticas de qualidade de software relacionadas a: testes, tratamento de erros, refatoração, documentação e versionamento.

## 3. Problema
Durante o desenvolvimento da aplicação FinançApp, foi identificada a necessidade de criar um módulo matemático reutilizável que não apenas funcionasse corretamente, mas também apresentasse código legível, testes automatizados, tratamento de falhas e documentação técnica.

## 4. Objetivo
### 4.1 Objetivo Geral
Desenvolver uma calculadora em Java aplicando práticas de qualidade, testes, documentação, refatoração e versionamento.

### 4.2 Objetivos Técnicos
* Implementação de operações matemáticas básicas;
* Tratar entradas inválidas e divisão por zero;
* Desenvolver testes automatizados;
* Refatorar o código sem alterar seu comportamento;
* Documentar classes e métodos com JavaDoc;
* Gerar documentação HTML;
* Utilizar Git e GitHub mantendo branches e commits organizados.

## 5. Escopo Funcional
A aplicação oferece as seguintes operações:
| ID   | Funcionalidade          | Descrição                          | Status |
|------|-------------------------|------------------------------------|--------|
| RF01 | Soma                    | Soma dois números inteiros         | ✅      |
| RF02 | Subtração               | Subtrai dois números inteiros      | ✅      |
| RF03 | Multiplicação           | Multiplica dois números inteiros   | ✅      |
| RF04 | Divisão                 | Divide dois números inteiros       | ✅      |
| RF05 | Validação de Divisão    | Impede divisão por zero            | ✅      |
| RF06 | Tratamento de Operador  | Trata operadores não suportados    | ✅      |

## 6. Requisitos Não Funcionais
| ID    | Categoria      | Requisito                                                     |
|-------|----------------|---------------------------------------------------------------|
| RNF01 | Qualidade      | O código deve possuir organização e legibilidade              |
| RNF02 | Testabilidade  | As operações devem possuir testes automatizados (JUnit)       |
| RNF03 | Manutenção     | O código deve permitir a refatoração sem alteração funcional  |
| RNF04 | Documentação   | Classes e métodos devem possuir JavaDoc                       |
| RNF05 | Versionamento  | O projeto deve usar Git e GitHub com branch "Refatoracao"     |
